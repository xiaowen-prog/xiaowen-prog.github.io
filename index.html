项目案例

让个人网站，
从展示变成证据。

这个网站也是一个持续迭代的产品：从示例作品集，到文章、开源工具与个人介绍的统一入口。

问题

最初的作品卡只有概念示例。换上真实项目后，封面仍重复项目名，访客无法从页面判断具体交付内容；首屏与内容区的字体和色调也缺乏连续性。

设计取舍

保留云海与玻璃雕塑作为识别点；四个 Skill 以真实 README 的流程、提示词和验收规则呈现。项目名称保留在卡片下方，让封面承担“展示产出”的职责。

交互取舍

只保留与浏览任务有关的反馈：标题切换指向真实项目、分类筛选、微信号复制。移除整页重复的淡入，让内容直接出现，并支持减少动态效果。

交付与验证

已接入五个指定公开项目、四篇精选文章与联系方式；源码公开，可逐项核对。首屏图片由约 2.2MB 的 PNG 改为约 458KB 的 JPEG，此处仅比较图片资源，不代表整页加载量。
